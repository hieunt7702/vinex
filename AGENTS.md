## 2. Liquid Glass Design System Tokens
- **Brand Colors**:
  - Deep Teal: `#074751` & `#0D5962`
  - Warm Ivory: `#FAF8F2`
  - Accent Gold: `#F2B719` / `#D4AF37`
  - Sage Botanical: `#5C7B6C`
- **Glass Tokens**:
  - Header / Dock: `backdrop-blur(24px) saturate(140%)`, `border: 1px solid rgba(255, 255, 255, 0.45)`, `background: rgba(255, 255, 255, 0.2)`
  - Cards: `backdrop-blur(24px) saturate(140%)`, `border: 1px solid rgba(255, 255, 255, 0.45)`, `box-shadow: 0 16px 40px rgba(7, 71, 81, 0.08), inset 0 1.5px 2px rgba(255, 255, 255, 0.7)`
  - Buttons (Primary): Pill shape with glowing ambient cyan-teal aura (`from-teal-400/50 to-cyan-400/40 blur-md`), gradient from `#074751` to `#146b76`, gold accents.
  - Buttons (Secondary / Liquid): Pill shape with `backdrop-blur-md bg-white/70 border border-white/80`.
- **Principles**:
  - Always provide instant CSS glass fallback to eliminate hydration flicker.
  - Ensure high contrast for text over glass (`#074751` on light glass, `#FFFFFF` on dark glass).
  - Use specular sheen gradients (`inset 0 1.5px 2px rgba(255, 255, 255, 0.75)`) to create authentic optical glass thickness.
